# Unpause 1.0 preview

A native consumer app for returning to unfinished physical projects, created by Shivam Gupta for RevenueCat Shipaton 2026.

## Install and explore

Download **unpause-galaxy-preview.apk** onto a modern arm64 Android device. Allow installation from the trusted source you use to open the APK, install it, and choose **Explore a sample studio**. The app bundles its JavaScript and fonts and runs without Metro or an internet connection for its local features.

This is a **test-signed preview**, not a production-signed Galaxy Store release. It does not contain owner-specific Supabase or RevenueCat keys. Missing account or purchase configuration is reported honestly. A later production certificate may require uninstalling this preview; export your project backup first if you have added personal data.

## Included

- Time and energy matching; project shelf; stopping point, next action, and materials memory.
- Persistent making sessions and checkpoints; project completion; local photos and reminders.
- Validated portable backups with embedded photos; explicit destructive-action confirmation.
- Optional Supabase account lifecycle and real RevenueCat lifetime purchase integration, ready for owner configuration.
- Android, iOS, and web source/build profiles; 93 unit/service tests and 20 browser scenarios.
- Editable pitch deck, PDF judge brief, original icon, native screenshots, and silent walkthrough reference.
