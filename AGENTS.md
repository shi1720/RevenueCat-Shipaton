# Unpause
Consumer Expo React Native app for resuming physical creative projects. Shivam Gupta is project creator.

- TypeScript strict mode. Keep domain logic pure and testable.
- Native iOS, Android (Google and Galaxy stores), and web must bundle.
- Local mode must work without credentials. Never simulate a successful authentication, purchase, cloud sync or store deployment.
- Never commit credentials, signing keys, generated builds, or customer data.
- Preserve user data on malformed imports or failed storage writes. Validate imported records.
- Do not invent traction, outcomes, founder history, or hackathon eligibility.
- Run npm run typecheck, npm test, and npm run export:web before delivery.
- Browser tests should exercise creating, pausing, resuming, finishing, and persistence.
